# 客服收發台 驗收清單

每一條都是「做什麼 → 應該看到什麼」。驗收以正式環境、真實 LINE 帳號為準。
電腦模式 = 視窗寬度 1024px 以上；手機模式 = 1024px 以下（電腦瀏覽器縮窄也算）。
原則：電腦像 macOS 的「訊息」，手機像 LINE；畫面只回答「現在怎麼了、我要做什麼」。

## 一、兩種模式共通

| 做什麼 | 應該看到 |
| --- | --- |
| 開啟網址 `/` 並登入（名稱＋密鑰） | 進入對話清單；名稱顯示在右上角 |
| 重新整理頁面 | 停在同一個對話或同一個頁面，不回到首頁 |
| 瀏覽器上一頁 | 回到前一個對話／關閉面板／關閉對話框，順序與操作相反 |
| 使用者在 LINE 傳文字 | 3 秒內出現在對話裡，清單該對話跳到最上面並顯示未讀數 |
| 客服打開該對話 | 未讀數歸零；若官方帳號 Chat 已開啟，使用者的 LINE 顯示「已讀」 |
| 客服送出文字 | 泡泡立即出現並標「發送中」，1 秒內變「已發送」；使用者 LINE 收到同一段文字 |
| 送出時拔掉網路 | 泡泡停在「發送中」，網路恢復後 5 分鐘內自動變「已發送」，使用者只收到一次 |
| 連點兩次「發送」 | 只送出一則 |
| 另一位客服先回了 | 自己按發送時出現「某某已於您之後回覆」，可取消或仍要發送 |
| 按「接手」 | 標題列顯示「由您負責」，清單該對話出現名稱標籤；另一位客服回覆時被提醒 |
| 滑過（或觸控時直接看到）泡泡旁的「!」並按下 | 立即顯示「已回報」，不出現任何浮層 |
| 按泡泡旁的「引用」再送文字 | 輸入框上方出現引用列；送出後客服台與使用者的 LINE 都顯示引用框 |
| 使用者在 LINE 引用客服訊息 | 客服台泡泡上方顯示「引用客服訊息」與原文 |
| 使用者引用串接前的訊息 | 顯示「引用的原始訊息無法取得」，不顯示空白 |
| 使用者一次傳 6 張圖 | 一個泡泡、六格、順序與 LINE 相同；下載中的格子顯示「下載中」 |
| 使用者撤回 | 泡泡變成「此訊息已被使用者撤回」，附件消失 |
| 群組中有人編輯文字 | 泡泡文字更新並標「已編輯」 |
| 任何對話框或下拉清單開著時按 Escape 或點外面 | 關閉 |

## 二、電腦模式（像軟體）

| 做什麼 | 應該看到 |
| --- | --- |
| 開啟 | 左清單、右對話同時存在；清單不會因為選了對話而消失 |
| 按 ⌘K（Windows：Ctrl+K） | 游標跳到搜尋框 |
| 焦點不在輸入框時按 ↑ ↓ | 切換上一個／下一個對話 |
| 在輸入框按 Enter | 發送；Shift+Enter 換行 |
| 滑過泡泡 | 旁邊出現「引用」與「!」；移開就消失 |
| 開啟追蹤訊息等頁面 | 取代右側內容；按「關閉」或 Escape 回到對話 |

## 三、手機模式（像 LINE）

| 做什麼 | 應該看到 |
| --- | --- |
| 開啟 | 只有清單，上方標題，下方分頁列（對話、追蹤、匯入、通知） |
| 點一個對話 | 整個畫面變成該對話：上方對方名稱與返回鍵，下方輸入列固定；分頁列消失 |
| 按返回鍵或手機的上一頁 | 回到清單，停在原本捲動位置 |
| 在輸入框按 Enter | 換行；按「發送」才送出 |
| 看泡泡 | 「引用」與「!」一直顯示（沒有滑過這回事） |
| 直向轉橫向 | 版面不壞、輸入列不被鍵盤蓋住 |
| 把電腦瀏覽器縮窄到手機寬度 | 立即變成手機模式；拉寬變回電腦模式，選取的對話不變 |

## 四、與 LINE 手機端對照（持續補充）

用同一個測試帳號傳下列內容，兩邊截圖比對；差異一律在客服台的呈現層修正。

| 傳送內容 | LINE 顯示 | 客服台目前 | 狀態 |
| --- | --- | --- | --- |
| 多張圖片 | 一則格子 | 一則格子 | 完成 |
| 引用 | 引用框＋原文 | 引用框＋原文（串接後的訊息） | 完成 |
| LINE emoji | 圖片 | 佔位字元 | 待做 |
| @提及 | 加粗名稱 | 純文字 | 待做 |
| 貼圖 | 動態／靜態貼圖 | 靜態貼圖 | 接受 |
| 組合貼圖 | 組合圖 | 無法取得 | LINE 不提供，標示 |
| 語音 | 播放鍵＋秒數 | 播放器 | 待補秒數 |
| 位置 | 地圖縮圖 | 文字連結 | 待做 |
| 檔案 | 檔名＋大小 | 檔名＋大小 | 完成 |
| 我方訊息是否被已讀 | 已讀 | 不顯示 | LINE 不提供，不顯示 |
